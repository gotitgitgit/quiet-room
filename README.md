# 아무도 듣지 않는 방 (접속 서버 버전)

링크 하나로 누구나 들어와 같은 방에 함께 있을 수 있는 3D 고해실입니다.
곰 인형만 듣고, 쓴 글은 태워 없앱니다.

## 개인정보 / 동작 방식
- 서버가 주고받는 것은 **위치, 앉은 자리, 번호표 순서**뿐입니다. 이름·계정·글은 받지도 저장하지도 않습니다.
- 쓴 글은 브라우저 밖으로 나가지 않습니다. 태우면 사라지고, "남겨두기"를 누르면 그 사람 브라우저(localStorage)에만 저장됩니다.
- 서버는 디스크에 아무것도 쓰지 않습니다. 재시작하면 방이 비워질 뿐입니다.
- 번호표 시각은 서버 시계로 찍어서, 사람마다 컴퓨터 시계가 달라도 순서가 어긋나지 않습니다.
- 부스는 앉은 때부터 최대 3분입니다(30초 전 알림, 시간이 지나면 쓴 글은 태워지고 자리에서 일어남).
- 한 방에 40명까지, 넘치면 새 방이 열립니다(최대 25방). 같은 주소에서는 탭 6개까지입니다.
- 배경음악은 브라우저에서 직접 만들어 내는 소리라 저작권 문제가 없습니다.

## 내 컴퓨터에서 실행
```
npm install
npm start
```
http://localhost:3000 을 열면 됩니다. 같은 와이파이의 다른 기기는 `http://내컴퓨터IP:3000` 으로 들어옵니다.

## 인터넷에 올리기 (예: Render)
1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 제외, `.gitignore`에 들어 있음).
2. render.com → New → Web Service → 저장소 선택. `render.yaml`이 있어 설정이 자동으로 채워집니다.
   직접 입력한다면: Build `npm install`, Start `npm start`.
3. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 공유하면 끝입니다.

Railway, Fly.io, 일반 VPS(Node 18 이상)에서도 `npm install && npm start`로 똑같이 동작합니다.
`PORT` 환경변수를 자동으로 읽습니다.

참고
- 무료 요금제는 한동안 접속이 없으면 잠들어서 첫 접속이 느릴 수 있습니다.
- HTTPS 주소에서는 자동으로 `wss://`로 연결됩니다. WebSocket을 막는 프록시 뒤에서는 동작하지 않습니다.
- `index.html`을 파일로 직접 열면 서버 없이 혼자 있는 방으로 열립니다.

## 설정 (환경변수, 모두 선택)
| 이름 | 기본값 | 설명 |
|---|---|---|
| PORT | 3000 | 포트 |
| MAX_PER_ROOM | 40 | 한 방 최대 인원 |
| MAX_ROOMS | 25 | 최대 방 수 |
| MAX_PER_IP | 6 | 같은 주소 동시 접속 수 |
| ALLOWED_ORIGINS | (비움) | 쉼표로 구분한 허용 주소. 비우면 같은 도메인만 허용 |
| TRUST_PROXY | 1 | 0이면 X-Forwarded-For를 믿지 않음 (프록시 없이 직접 공개할 때) |

## 알려진 한계
- 이용 시간 3분 제한은 각자 브라우저에서 지켜집니다(고쳐 쓰면 우회 가능). 서버가 강제하지는 않습니다.
- 두 사람이 정확히 같은 순간에 같은 고해실에 들어가거나 같은 자리에 앉는 경우를 서버가 막아주지는 않습니다(드물게 겹쳐 보일 수 있음).
- 서버 한 대 기준입니다. 여러 대로 늘리면 방이 서로 나뉩니다.
